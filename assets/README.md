# Assets

This folder contains screenshots and images for documentation.

## Files

- `agent-answer.jpg` - Screenshot showing agent's email response

## How to Add Screenshots

1. Take a screenshot of the email response
2. Save it as `email-response-example.png` in this folder
3. The image will automatically appear in the main README.md

## Recommended Screenshot Content

Show:
- Original user question email
- Agent's automatic response
- Timestamp showing quick response time
- Professional email formatting
